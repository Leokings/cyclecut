Title
CycleCut - Consensus dependency cycle cutting

Notes / Description
Built CycleCut, a reusable GenLayer Intelligent Contract that derives a bounded dependency graph from public planning text, detects feedback cycles deterministically, proposes one concrete edge at a time, records owner-approved cuts, and seals a stable topological order. The contract separates the semantic validator task from deterministic validation, authorization, cycle detection, and ordering. GenVM lint and strict type checking pass; 16 direct security tests and a five-validator integration flow pass. A fresh StudioNet run finalized inference, cut [2,0], sealed order [0,1,2], read the final state, and proved the deployed source exactly matches the repository.
